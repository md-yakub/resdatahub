# ResDataHub Backend Development Instructions

## Before making changes

- Always inspect the existing code first.
- Explain your implementation plan before writing code.
- Implement only the requested feature.
- Never modify unrelated code.
- Keep code simple and readable.
- Follow Spring Boot best practices.
- Use constructor injection.
- Never return JPA entities directly from controllers.
- Use DTOs.
- Validate request bodies.
- Use Flyway for schema changes.
- Explain every file you modify.

## Coding Style

- Prefer readable code over clever code.
- Avoid unnecessary abstractions.
- Write beginner-friendly Java.
- Keep methods short.
- Use meaningful class names.
